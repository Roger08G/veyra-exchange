
# Tokens

Para Veyra `v0.1.0` solo se permite exclusivamente el modelo `ERC-20` utilizando dos activos de preuba con funciones diferentes.

- **MockUSD (6):** Moneda estable simulada para depósitos, retiradas, pagos, comisiones y préstamos.
- **MockETH (18):** Activo de valor variable utilizado principalmente como garantiía de los préstamos.

Veyra mantiene una *white list* de tokens admitidos y en esta versión solo acepta **MockUSD** y **MockETH** rechazando cualquier otor token.
